# Matt Pocock engineering skills

The existing local Matt installation is retained. This repository now supplies
the GitHub tracker, triage vocabulary, single-context glossary and ADR layout
used by setup-matt-pocock-skills, to-spec, to-tickets, domain-modeling and
code-review. The user's instruction on 13 October 2026 authorized this setup
and publication of the planning tasks; GitHub follows the existing remote.

The missing stable engineering skills `implement-spec`, `pr` and `retro` were
installed from [mattpocock/skills at 49dd158](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336/skills/engineering).
Existing installed skills were preserved; experimental skills were not added.
Newly installed skills become available to Codex on the next turn.

Skills are local tools, not runtime dependencies of this project. Another
contributor should install the skills from that source through their agent's
supported installer, then use the committed `docs/agents/` configuration.
